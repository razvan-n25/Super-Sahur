### Super Sahur
Super Sahur este un joc cu un singur nivel, in care jucatorul controleaza personajul principal, Sahur. Personajul incepe cu 5 inimi de viata, iar la fiecare obstacol lovit pierde cate o inima. Scopul jocului este de a parcurge toate obstacolele si de a ajunge la finalul nivelului. Jocul este asemanator jocului Super Mario.
